### 🍳 Retseplar Dunyosi
*World of Recipes*

![React](https://img.shields.io/badge/React-000000?style=flat-square&logo=react&logoColor=00f0ff)
![Status](https://img.shields.io/badge/Status-In%20Development-000000?style=flat-square&labelColor=ff9d00)

A React recipe application that helps users discover what they can cook based on the ingredients they already have.

**The problem:** people often have ingredients at home but don't know what to cook.

**The idea:** suggest meals, salads, desserts, and other recipes from what the user already has. Made for anyone who cooks at home, including people just starting to cook.

**Planned / in-progress features**
- Recipe recommendations
- Ingredient-based suggestions
- Favorites with a heart button
- Required ingredients list
- Step-by-step cooking instructions
- AI-based recipe suggestion *(concept)*

**Architecture ideas:** `api/recipes.json` · `common/layout` · recipe components · favorites context · hooks · pages · React Router

### 📚 Library Management System
*School library tracker*

![Frontend](https://img.shields.io/badge/Frontend-Project-000000?style=flat-square&labelColor=1f6feb)
![Status](https://img.shields.io/badge/Status-Concept-000000?style=flat-square&labelColor=ff4fd8)

A school project idea to replace paper-based library records with a digital system for managing books and students.

**Planned functionality**
- Book registration and numbering
- Recording and marking books
- Search by book number, title, or student's first/last name
- Class-based management
- Teacher access for their own class
- Librarian / admin role

> This is a school project concept, not a deployed product.
